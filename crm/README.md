# TWELVE — عقارات

## التطبيق

**[`broker/`](broker/)** — بوابة البروكر. مستخدم واحد بس: البروكر يسجّل
دخوله، يشترك في داتا، ويفتحله شيت يتصل منه. ملف واحد مكتفي بذاته، بيفتح
بسرعة وبيشتغل أوفلاين.

```bash
node crm/broker/build.mjs        # يبني dist/index.html
```

التفاصيل في [`broker/README.md`](broker/README.md).

## الباك إند (اختياري — لسه مش موصّل)

**[`supabase/`](supabase/)** — سكيما PostgreSQL كاملة مع عزل بين المستأجرين
(Row-Level Security) ومحرك توزيع ليدز، متكتوبة ومختبَرة.

اتبنت للنسخة الأقدم متعددة البوابات (وكالة + شركات + أدوار)، فهي **أوسع من
منتج البروكر الحالي**. سايبها زي ما هي لأنها شغل شغّال ومختبَر ممكن يفيد لو
حبيت تنقل البيانات لسيرفر بعدين، لكنها محتاجة تبسيط عشان تطابق النموذج
الحالي. قول لو عايزني أبسّطها أو أشيلها.
