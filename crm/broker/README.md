# TWELVE — بوابة البروكر

تطبيق واحد لمستخدم واحد: **البروكر**. يسجّل دخوله، يشترك في داتا، ويفتحله
شيت يتصل منه. مفيش أدوار، مفيش لوحات إدارة، مفيش تعقيد.

## المسار

```
تسجيل الدخول  →  اشتراك داتا  →  لصق الشيت  →  اتصل واشتغل
```

1. **الدخول** — اسم ورقم. مفيش سيرفر: الحساب والبيانات كلها على الجهاز.
2. **الاشتراكات** — كل اشتراك = شيت داتا (اسم، منطقة، مصدر) وبيبان عليه
   نسبة اللي خلّصته منه.
3. **الشيت** — انسخ الأعمدة من Excel أو Google Sheets والصقها. التطبيق
   بيحدّد عمود الاسم وعمود الرقم **من قيم البيانات نفسها** مش من ترتيب
   الأعمدة، وبيشيل السطر العنواني والمكرر — وبيوريك بالظبط هيتسجّل كام
   قبل ما يحفظ حاجة.
4. **الشغل** — كل صف فيه اتصال وواتساب بضغطة. زرار «التالي» بينقلك على أول
   رقم لسه مااتكلمش. تفتح الرقم تحدّد حالته وتكتب ملاحظة.

## الحالات

`جديد` · `تم الاتصال` · `مهتم` · `أعاود لاحقاً` · `تم البيع` · `غير مهتم`

## البنية

```
crm/broker/
├── src/
│   ├── index.html            الهيكل (shell)
│   ├── styles/
│   │   ├── 01-tokens.css     ألوان البراند (فاتح/غامق)
│   │   ├── 02-base.css       الأساسيات والحركة
│   │   ├── 03-components.css الأزرار، الحقول، الـ chips، الـ dialog
│   │   ├── 04-layout.css     الهيكل العام وشاشة الدخول
│   │   └── 05-screens.css    الاشتراكات والشيت
│   └── js/
│       ├── 01-icons.js       أيقونات SVG + علامة البوصلة
│       ├── 02-utils.js       تنسيق، روابط الاتصال، قارئ الشيت
│       ├── 03-store.js       التخزين والحالات
│       ├── screens/
│       │   ├── 10-auth.js
│       │   ├── 20-packages.js
│       │   └── 30-sheet.js
│       └── 90-app.js         الراوتر والنوافذ والتشغيل
├── build.mjs                 يدمج src في ملف واحد
└── dist/index.html           الناتج — يشتغل بمجرد فتحه
```

## البناء

```bash
node crm/broker/build.mjs      # → dist/index.html
```

المصدر مقسّم بالمنطق، والناتج ملف واحد مكتفي بذاته: **صفر طلبات شبكة**،
صفر مكتبات خارجية — عشان يفتح بسرعة ويشتغل أوفلاين.

## البيانات

كل شيء في `localStorage` تحت المفتاح `twelve_broker_v1`، على جهاز البروكر
وحده. مفيش بيانات وهمية مزروعة: الحساب الجديد بيبدأ فاضي فعلاً.
